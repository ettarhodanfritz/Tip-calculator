# Tip Calculator React App

A simple **React** app to calculate tips based on user input and service ratings. Users can input the bill amount, select service ratings for themselves and a friend, and see the tip amount as well as the total bill. Includes a reset button to clear inputs.

## Features

- Input bill amount  
- Select service satisfaction percentage (user and friend)  
- Calculate the average tip  
- Display total bill including tip  
- Reset button to clear inputs  

## Components

- **TipCalculator** – Main component managing state and tip calculation  
- **BillInput** – Input field for the bill amount  
- **SelectPercentage** – Dropdown to select satisfaction percentage  
- **Output** – Displays the total bill and tip  
- **Reset** – Resets all inputs to default
